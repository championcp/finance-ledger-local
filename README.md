# 家庭理财台账 · 本地版

一台 Mac 上的私人理财台账：数据只存本机 SQLite，服务只绑 `127.0.0.1`，打开 App 时自动从官网抓一次净值。不上传云端，不存账号密码，手机与外网无法访问。

手动模式：**没有开机自启、没有后台常驻**。打开 App 才启动服务，关闭 App 就彻底退出并释放端口。

## 启动与退出

```bash
bash install.sh        # 仅首次安装：建虚拟环境、装依赖（不装开机自启）
```

- 启动：双击 `dist/家庭理财台账.app`（独立窗口）。打开时会自动抓一次净值、做一次备份，数据稍后自动刷新。
- 退出：关闭窗口即彻底结束，31415 端口随之释放。
- 浏览器：`http://127.0.0.1:31415`（只在 App 开着时可访问）

> 监听端口固定为 `31415`（冷门、避免冲突），统一在 `config.py` 定义；如需改用其他端口，改那里的 `PORT` 即可。

手动启动（调试用）：`.venv/bin/python app.py`（用 `Ctrl+C` 停止）

## 登记

只在一个地方登记：页面「我的理财」→ 新增一笔。

- 存款/大额存单：填名称、分类、当前金额即可。
- 理财产品：另填净值代码、持有份额。净值由系统每天自动抓取，市值 = 份额 × 净值，不用手算。
- 净值代码：管理人官网的份额代码；不知道就填银行 App 的销售代码，映射在 `mapping.json` 维护。
- 持有份额是私有数据，官网接口拿不到，需要从银行 App 持仓详情抄填一次。

## 导出 Excel

点页面工具栏的「↓ 导出 Excel」，会把「我的理财」里登记的明细导出为一个 `.xlsx` 文件，下载到浏览器默认下载目录。

- 每笔资产一行，含名称/分类/币种/本金/当前金额、净值代码/份额/净值/净值日期、折合人民币、收益、到期日等完整字段，末尾有合计行。
- 多币种按「汇率设置」里的汇率折合人民币；收益按中国习惯标色（红=盈利，绿=亏损）。
- 只导出你登记的数据，不导出系统自动生成的流水/快照/留痕；导出是只读操作，不改数据。
- 导出的文件含真实资产信息，请勿上传到公开网盘或代码仓库。

## 备份

每次打开 App 时自动备份一次到 `data/backups/finance_YYYYMMDD_HHMMSS.db`，只保留最近 30 份，旧的自动清理。备份用 SQLite 在线接口生成，读写时也能安全备份。日志在 `data/backup.log`。

手动备份（随时可跑）：

```bash
.venv/bin/python backup.py
```

改保留份数（默认 30）：`FINANCE_BACKUP_KEEP=60 .venv/bin/python backup.py`

恢复：先停掉服务（关掉桌面窗口 / `bash uninstall.sh`），把选中的备份文件复制回 `data/finance.db`，再重新启动。恢复前建议先把当前 `data/finance.db` 另存一份，避免覆盖后悔。

> 提醒：备份和数据库都在同一台 Mac 上。如果磁盘损坏，两者会一起丢失。重要数据请定期把 `data/backups/` 拷到移动硬盘。备份文件含你的真实资产信息，别上传到公开网盘或仓库。

## 卸载

```bash
bash uninstall.sh      # 只清理可能的历史定时任务，不删数据
```

## 目录

- `app.py` / `storage.py` / `nav_fetch.py` / `desktop.py` / `backup.py`：服务、数据层、抓取、桌面入口、备份
- `web/index.html`：页面
- `seed.example/`：数据格式示例（假数据）
- `mapping.json`：销售代码 → 官网份额代码映射
- `deploy/`：launchd 配置模板（手动模式下不使用，留作备用）
- `docs/`：设计与维护说明

## 安全边界

- 服务只监听 `127.0.0.1`，手机/局域网/外网访问不到。
- 不收集账号密码，只记录产品名称、金额、时间周期。
- 体检与提醒是结构规则提示，不构成具体投资建议。
