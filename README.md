# 家庭理财台账 · 本地版

一台 Mac 上的私人理财台账：数据只存本机 SQLite，服务只绑 `127.0.0.1`，净值每天自动从官网抓取。不上传云端，不存账号密码，手机与外网无法访问。

## 启动

```bash
bash install.sh        # 首次安装：建虚拟环境、装依赖、配置开机自启与每日抓净值
```

- 桌面：双击 `dist/家庭理财台账.app`（独立窗口）
- 浏览器：`http://127.0.0.1:8765`

手动启动（调试用）：`.venv/bin/python app.py`

## 登记

只在一个地方登记：页面「我的理财」→ 新增一笔。

- 存款/大额存单：填名称、分类、当前金额即可。
- 理财产品：另填净值代码、持有份额。净值由系统每天自动抓取，市值 = 份额 × 净值，不用手算。
- 净值代码：管理人官网的份额代码；不知道就填银行 App 的销售代码，映射在 `mapping.json` 维护。
- 持有份额是私有数据，官网接口拿不到，需要从银行 App 持仓详情抄填一次。

## 备份

复制 `data/finance.db` 即可。恢复时放回原位置。

## 卸载

```bash
bash uninstall.sh      # 只卸载开机自启与定时任务，不删数据
```

## 目录

- `app.py` / `storage.py` / `nav_fetch.py` / `desktop.py`：服务、数据层、抓取、桌面入口
- `web/index.html`：页面
- `seed.example/`：数据格式示例（假数据）
- `mapping.json`：销售代码 → 官网份额代码映射
- `deploy/`：launchd 配置模板
- `docs/`：设计与维护说明

## 安全边界

- 服务只监听 `127.0.0.1`，手机/局域网/外网访问不到。
- 不收集账号密码，只记录产品名称、金额、时间周期。
- 体检与提醒是结构规则提示，不构成具体投资建议。
