# 关键坑与实测情报

## 净值接口

`https://www.bocwm.cn/webApi/cms/productNetWorth/getNetWorthByCode?productCode=<代码>&pageNo=1&pageSize=10`

- 免登录、免签名、免验证码。
- 返回 `data` 数组按日期**升序**：最后一条才是最新净值。取第一条会拿到旧数据。
- 页面前端受跨域限制抓不了，必须由本机 Python 抓取。

## 代码映射

台账里登记的可能是销售代码，官网接口只认份额代码。映射关系需从官网、产品说明书、销售渠道页面交叉验证，不能猜。已知一条映射写在 `mapping.json`，新增产品按同样方式维护。

## 数据格式

写入是包裹格式，读取必须返回扁平标量。这是页面数字能否正确显示的关键。

## 持有份额

市值 = 份额 × 净值。净值能抓，份额是私有数据接口拿不到，必须用户从渠道 App 持仓详情抄填一次。这一步无法自动化。

## 异步留痕

写入主记录后，留痕和快照的写入必须纳入同一 Promise 链；否则页面会先重载，导致刚写完的操作在历史里暂时看不到。

## 本机 launchd

- 新 macOS 优先 `launchctl bootstrap gui/<uid>`，旧 `load` 可能返回 I/O error。
- AI 执行环境常无法写 launchd；安装脚本在用户自己的终端执行即可。
